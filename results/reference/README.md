# Manuscript reference values

`manuscript_reported_stage_contrasts.csv` is a machine-readable transcription
of the posterior medians and 95% credible intervals in the revised Results text
available on 2026-08-30. It is included so regenerated summaries can be checked
against the prose.

This file is **not** a posterior-draw cache and cannot reproduce a density plot,
diagnostics, or a fitted model. The analysis never reads it as input. Rows with
blank comparison counts inherit the context-level comparison set described in
the manuscript, but the count is intentionally left blank because the prose did
not repeat it for each metric-specific estimate.
